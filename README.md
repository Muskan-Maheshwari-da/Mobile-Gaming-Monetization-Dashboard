# 🎮 Mobile Gaming Monetization Executive Dashboard

An end-to-end data analytics project exploring mobile gaming revenue streams, user behavior, geographic performance, and platform-specific engagement metrics. Built with a custom dark neon UI aesthetic in Power BI, backed by Python data analysis pipelines.

## 💡 Key Business Questions & Insights Addressed
1. **ARPU & Spending Segments:** Segmented players into **Whales**, **Dolphins**, and **Minnows** to identify high-value customer cohorts driving revenue.
2. **Geographic Performance:** Analyzed top revenue-generating countries across global markets to optimize regional targeting.
3. **First Purchase Timing:** Tracked the average days from app installation to the first in-app purchase (`FirstPurchaseDaysAfterInstall`) to optimize promotional timing.
4. **Device & Platform Impact:** Compared user engagement (`SessionCount`, `AverageSessionLength`) and monetization trends between Android and iOS users.
